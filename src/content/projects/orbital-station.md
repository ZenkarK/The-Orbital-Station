## Objective

A home for the work: one place where projects, notes and essays accumulate into something durable, instead of scattering across notebooks and tabs.

## Revision history

- **Rev 1–4** — a single self-contained HTML file. No framework, no build; content lived in the browser's local storage.
- **Rev 5** — rebuilt as a static site. Every transmission, mission, and library holding is now a plain file in the repository, so the whole station is versioned, portable, and readable by anyone who visits.

## Design constraints

- Fast and quiet: static pages, self-hosted fonts, no tracking.
- The orrery on the Bridge stays the control, not a decoration.
- Writing a new post should take nothing more than a Markdown file.
